# Movie App

Welcome to Movie App! This project is a React application designed to allow users to browse movies, view movie details, add movies to their wishlist, and search for movies.

## Main Idea

The main idea behind Movie App is to provide users with a platform to discover and explore movies. Users can browse a list of popular movies, view movie details, search for specific movies, and manage their wishlist of movies they want to watch.

## Pages

Movie App consists of the following pages:

- **Movies List Page (Main Page)**: Displays a list of popular movies.
- **Movie Details Page**: Shows detailed information about a selected movie, including recommendations.
- **Movies Wishlist**: Displays a list of movies added to the user's wishlist.
- **Movies Search Results**: Shows search results based on user input.

## Features

Movie App offers the following features:

- Browse popular movies using the [TMDB API](https://www.themoviedb.org/documentation/api).
- Paginate through the list of movies.
- View detailed information about each movie.
- View recommended movies for each selected movie.
- Search for movies based on title.
- Add movies to the wishlist.
- Toggle wishlist action on movie cards.
- Remove movies from the wishlist.
- Visit the wishlist page to manage wishlist items.
- Bonus: Switch between languages and update layout direction accordingly.
- Bonus: Add and remove movies to watchlist using additional TMDB API endpoints.
